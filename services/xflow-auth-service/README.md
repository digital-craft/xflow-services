# Auth Service

Le service d'authentification (`xflow-auth-service`) gère la sécurité de la plateforme XFlow.

## Fonctionnalités
- Gestion des utilisateurs et des rôles.
- Authentification via JWT (JSON Web Tokens).
- Support des tokens de rafraîchissement.
- Envoi d'emails de vérification.

## Configuration
Le service utilise les variables d'environnement définies dans le fichier `.env` à la racine du projet.

## API
La documentation OpenAPI est disponible à l'adresse `/swagger-ui.html` lorsque le service est démarré.
